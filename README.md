# Hyman-et-al-2026-Integrated-Tagging-Model
This worked example describes the integrated modeling framework used to estimate post-release survival from conventional tagging and acoustic telemetry data across a range ofenvironmental predictors, as developed in Hyman AC, Collins AB, Ramsay C, Wilms S, Allen MS, Barbieri L, Frazer TK. Integrating conventional tagging and acoustic telemetry improves estimates of post-release survival in a highly targeted reef fish. ICES Journal of Marine Science, Nov 2026; 83(11):fsag218. https://doi.org/10.1093/icesjms/fsag218
